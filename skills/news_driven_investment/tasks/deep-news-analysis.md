# 事件深度分析

以**事件**为单位，对快速分析标记为重要的事件进行多维度深入投资分析。

---

## 输入

- **EVENT_ID**: 事件 ID
- **EVENT_DIR**: 事件目录绝对路径
- **事件标题**: 事件标题
- **关联新闻列表**: 事件关联的全部新闻（标题 + summary）

---

## 分析流程

这是一个自由探索式的深度分析。根据事件内容，选择最有价值的分析维度，不必覆盖所有维度。

### 可用分析维度（按需选择）

- **板块趋势**: `openclaw_alpha_industry_trend` — 相关板块近期走势、热度变化
- **资金流向**: `openclaw_alpha_fund_flow_analysis` — 板块/个股资金净流入流出
- **技术指标**: `openclaw_alpha_technical_indicators` — 关键标的技术面信号
- **基本面**: `openclaw_alpha_fundamental_analysis` — PE/PB/ROE 等财务健康度
- **市场情绪**: `openclaw_alpha_market_sentiment` — 整体市场氛围
- **北向资金**: `openclaw_alpha_northbound_flow` — 外资动向
- **事件历史**: 读 `EVENT_DIR/responses/` 目录，了解历史市场反应

### 分析原则

1. **全面阅读**: 先读事件全部关联新闻（EVENT_DIR 下各 news_id 对应的 content.md），再读 responses/ 历史
2. **自由组合**: 根据事件性质选择分析维度，不必面面俱到
3. **交叉验证**: 用市场数据验证或修正从新闻得出的判断
4. **发现未知**: 每步分析后思考是否有新的值得深入的方向
5. **诚实原则**: 不确定就说不确定，不强行推断

---

## 产出

在 `EVENT_DIR/deep_analysis/` 下写入 `{YYYYMMDD}.md`（当天日期）。

### 报告结构

```markdown
# 深度分析：{事件标题}

**分析日期**: YYYY-MM-DD
**覆盖新闻**: N 条

## 事件脉络

{简述事件发展时间线}

## 多维度分析

### {维度1}: ...
### {维度2}: ...

## 投资洞察

### 确定性较高的判断
- ...

### 需要持续关注的信号
- ...

### 风险因素
- ...

## 后续跟踪建议

- 建议关注哪些后续新闻/数据
- 哪些信号出现时需要重新评估
```

### 报告要求

- 每个分析维度要有数据支撑（不是空谈）
- 投资洞察要具体到可操作的程度
- 区分"确定性判断"和"需要验证的假设"
- 标注信息来源（哪个 skill / 哪条新闻）
