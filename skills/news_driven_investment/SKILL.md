# 新闻驱动投资分析

从财经新闻中发现投资机会，关联产业分析和标的筛选。

## 核心流程

### 1. 获取新闻

```bash
uv run --env-file .env python -m openclaw_alpha.news.fetcher.news_fetcher --source cls_global --limit 20
```

**参数：**
- `--source` — 新闻源（默认 `cls_global`）
- `--limit` — 返回数量（默认 20）
- `--keyword` — 关键词筛选（匹配标题和内容）
- `--date` — 日期筛选（YYYY-MM-DD）
- `--symbol` — 股票代码（仅 `stock` 源使用）

完整数据源列表见 [references/data-sources.md](references/data-sources.md)。

### 2. 提取投资线索

阅读新闻，识别：
- **产业/概念方向** — 新闻直接或间接影响的板块
- **利好/利空** — 影响方向和力度
- **受益/受损标的** — 具体公司（含股票代码）

**关键判断：**
- 新闻是否已被市场消化？（看相关板块近期走势）
- 影响是短期情绪还是中长期逻辑？
- 是否存在预期差？（利好新闻 + 板块降温 = 潜在机会）

### 3. 验证与深化

对确认有价值的线索，调用其他 Alpha skill 交叉验证：板块热度、市场情绪、资金流向、标的筛选等。

**验证深度按线索价值决定：** 影响大、确定性高的多维度验证；轻微、不确定的点到为止。

## 分析原则

- **投资视角**：不是新闻摘要，是"这对投资有什么影响"
- **预期差优先**：市场共识外的信息才有超额收益
- **多维度交叉**：新闻 + 板块趋势 + 资金流向，单一维度不可靠
- **时效敏感**：新闻价值递减，尽快分析
- **风险意识**：新闻驱动多为短期机会，注意追高风险
